Project Overview

MyTvR is an immersive VR media application that transforms the Oculus headset into a virtual entertainment platform. The system consists of the MyTvR Oculus application and companion client applications for Windows and macOS. Client devices connected to the same local Wi-Fi network can select video content and stream it to the Oculus application for viewing inside different virtual environments.

The platform also provides access to popular streaming services such as Prime Video, Disney+ Hotstar, YouTube and Plex.

Key Features

  • Local Wi-Fi video streaming between client devices and the Oculus application
  • Cross-platform client applications for Windows and macOS
  • Video/content selection through companion client applications
  • Video playback inside the Oculus VR environment
  • Support for Prime Video, Disney+ Hotstar, YouTube and Plex
  • Multiple immersive viewing environments: Home, Theatre, Home Theatre and Space / Void
  • Interactive VR interface for navigating and accessing media

Technical Implementation

VR Application: Unity · C# · Oculus
Client Applications: .NET MAUI · C# · Windows · macOS
Connectivity: Local Wi-Fi
Focus: VR Development · Cross-Platform Applications · Network Streaming · Media Playback · UI · 3D Environments

The Oculus application was developed using Unity and C#, with multiple virtual environments designed around different media-viewing experiences.

Companion client applications were developed using .NET MAUI and C#, targeting Windows and macOS. These applications allowed users to select video content from their local devices and communicate with the MyTvR Oculus application over the local Wi-Fi network.

The system combined a Unity-based VR application with cross-platform .NET client applications, creating an end-to-end media streaming workflow between desktop devices and the Oculus headset.

Challenges & Solutions

Reliable video transfer over local Wi-Fi: The challenge was reliably delivering video data from a remote client device to the Oculus application during playback. ExoPlayer was used on the Android/Oculus side for media playback, with HTTP-based requests for video data. The remote MyTvR client acted as an HTTP server, listening for requests and responding with the required video data progressively.

Supporting online streaming platforms inside VR

The challenge was bringing web-based streaming services into the Oculus application while maintaining a browser-like experience within VR. Mozilla GeckoView, an Android browser component, was integrated to provide web browsing capabilities inside the application, allowing services such as YouTube, Prime Video, Disney+ Hotstar and Plex to be accessed within the VR environment.

Building a cross-platform streaming client

The remote client needed to work across different desktop platforms while communicating with the Oculus application. .NET MAUI and C# were used to develop the client applications for Windows and macOS while sharing the core application logic.

Integrating media playback with immersive environments

The challenge was presenting conventional video content as part of an immersive VR experience rather than a conventional media player. Multiple Unity environments—including Home, Theatre, Home Theatre and Space/Void—were developed and integrated with the media playback system.
