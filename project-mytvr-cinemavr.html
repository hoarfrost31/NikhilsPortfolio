Project Overview

MyTvR is an immersive VR media application that transforms the Oculus headset into a virtual entertainment platform. The system consists of the MyTvR Oculus application and companion client applications for Windows and macOS. Client devices connected to the same local Wi-Fi network can select video content and stream it to the Oculus application for viewing inside different virtual environments.

The platform also provides access to popular streaming services such as Prime Video, Disney+ Hotstar, YouTube and Plex.

Key Features

  • Local Wi-Fi video streaming between client devices and the Oculus application
  • Cross-platform client applications for Windows and macOS
  • Video/content selection through companion client applications
  • Video playback inside the Oculus VR environment
  • Support for Prime Video, Disney+ Hotstar, YouTube and Plex
  • Multiple immersive viewing environments: Home, Theatre, Home Theatre and Space / Void
  • Interactive VR interface for navigating and accessing media

Technical Implementation

VR Application: Unity · C# · Oculus
Client Applications: .NET MAUI · C# · Windows · macOS
Connectivity: Local Wi-Fi
Focus: VR Development · Cross-Platform Applications · Network Streaming · Media Playback · UI · 3D Environments
Target FPS: 72 FPS (~14 ms average frame time) during typical VR usage

Reliable HTTP video streaming on Android

Unity's built-in video playback system had limitations with certain video codecs and did not provide the reliability required for remote HTTP streaming on Android.

The Oculus application was integrated with Android's ExoPlayer, providing more capable media playback and HTTP streaming support. The remote MyTvR client applications act as HTTP servers, responding to requests from ExoPlayer and supplying requested video data progressively over the local network.

Supporting OTT streaming services inside VR

MyTvR needed to support browser-based streaming services such as YouTube, Prime Video, Disney+ Hotstar and Plex. Unity did not provide the required browser functionality for this use case.

Mozilla GeckoView was integrated into the Android/Oculus application to provide embedded browser functionality, allowing web-based streaming platforms to be accessed directly within the MyTvR VR environment.

Future Development

Shared multiplayer viewing: A planned extension of MyTvR is multiplayer functionality, allowing multiple users to join the same virtual Cinema or Theatre environment and watch content together, creating a shared social viewing experience.

Challenges & Solutions

Reducing UI rendering cost for large media libraries: MyTvR needed to display potentially large collections of videos and media items inside a VR interface. A UI object-pooling system was implemented for the Scroll Rect, allowing media containers to be reused instead of repeatedly instantiated and destroyed. Containers outside the visible area were disabled and re-enabled as required, reducing the number of active UI elements rendered at any given time.

Reducing UI rebuilds during animations

The VR interface contained animated UI elements where conventional Unity UI animation could cause additional UI rebuild work when elements became dirty. Instead of relying on Animator-based UI animations, script-based tweening was used to animate UI properties directly. This reduced unnecessary UI reload/rebuild cycles and helped keep the interface more efficient during interaction.

Rendering a detailed virtual cinema efficiently

The Cinema/Theatre environment contained many GameObjects to create a realistic theatre experience. Lightweight geometry and simplified materials/shaders were used for objects such as chairs farther from the user. Static batching and GPU instancing supported repeated geometry, while simplified baked lighting reduced runtime lighting calculations.
