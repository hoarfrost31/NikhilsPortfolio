MyTvR — CinemaVR

An immersive virtual cinema application designed to recreate the experience of watching movies inside a virtual theatre.

XR/VRUnityMedia Presentation
MYTVRVIRTUAL CINEMA

Project Overview

MyTvR is an immersive virtual cinema application where users enter a virtual theatre, interact with the environment, and access movie content through a VR interface.

Key Features

  • Immersive virtual cinema environment
  • VR-based navigation and interaction
  • Interactive movie and content selection
  • 3D environment and spatial UI elements
  • Virtual theatre designed for an immersive viewing experience

Technical Implementation

Engine: Unity
Language: C#
Focus: VR Interaction · 3D Environments · UI · Scene Design · Media Presentation

The virtual cinema environment was built in Unity, with scene design focused on a convincing theatre-like experience in VR. Interaction and navigation allow users to move through the space, while integrated UI elements connect the environment to movie and content selection.

Creating an immersive cinema environment

The theatre’s spatial layout, lighting, and interactive elements were designed around the user’s perspective inside the virtual space, making the environment feel natural to explore.

Designing intuitive VR interaction

VR-oriented interaction and spatial UI make navigation and content access straightforward and comfortable while retaining the sense of presence.
