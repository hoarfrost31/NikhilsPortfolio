XR / Unity Project

MyTvR — CinemaVR

An immersive virtual cinema application designed to recreate the experience of watching movies inside a virtual environment.

XR/VRUnityMedia Presentation

Project Overview

MyTvR is an immersive virtual cinema application designed to recreate the experience of watching movies inside a virtual environment. Users can enter a virtual theatre, interact with the environment, and access movie content through a VR interface.

Key Features

  • Immersive virtual cinema environment
  • VR-based navigation and interaction
  • Interactive movie and content selection
  • 3D environment and spatial UI elements
  • Virtual theatre designed for an immersive viewing experience

Technical Implementation

Engine: Unity
Language: C#
Focus: VR Interaction · 3D Environments · UI · Scene Design · Media Presentation

The virtual cinema environment was built in Unity, with the scene designed to provide an immersive theatre-like experience in VR. VR interaction and navigation allow users to move through and interact with the virtual environment. Interactive UI elements provide access to movie and content selection, connecting the virtual environment with the media-viewing experience.

Challenges & Solutions

Creating an immersive cinema environment: The environment, spatial layout, lighting, and interactive elements were designed around the user’s perspective inside the virtual space so the theatre feels natural to explore and use in VR.

Performance & Optimization

Designing intuitive VR interaction: The interaction system needed to remain simple and comfortable while allowing users to navigate the cinema and access content. VR-oriented interaction and UI elements were used to make common actions accessible within the virtual space.
