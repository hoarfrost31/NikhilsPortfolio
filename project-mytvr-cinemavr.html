Project Overview

MyTvR is an immersive VR entertainment application that transforms the Oculus headset into a virtual media-viewing platform. The application supports local Wi-Fi video streaming, allowing nearby devices running MyTvR client applications to connect to the Oculus app and stream selected video content directly into the virtual environment.

The platform also provides access to popular streaming services and multiple immersive environments, allowing users to choose different spaces for their viewing experience.

Key Features

  • Local Wi-Fi video streaming from connected client devices
  • MyTvR client applications for selecting and streaming video content
  • Video playback inside the Oculus VR application
  • Support for Prime Video, Disney+ Hotstar, YouTube and Plex
  • Multiple immersive viewing environments: Home, Theatre, Space / Void and Home Theatre
  • Interactive VR interface for navigating and accessing media
  • Immersive 3D environments designed around different viewing experiences

Technical Implementation

Engine: Unity
Language: C#
Platform: Oculus / VR · Local Wi-Fi Network
Focus: VR Development · Network Streaming · Media Playback · UI · 3D Environments · Device Integration

The Oculus application was developed in Unity and C#, with different virtual environments providing the foundation for the media-viewing experience.

A local Wi-Fi streaming system was implemented to allow nearby client devices running MyTvR applications to connect with the Oculus application. Users can select video content through the client application, which is then streamed to and viewed within the VR environment.

The application also integrates access to popular streaming platforms such as Prime Video, Disney+ Hotstar, YouTube and Plex. Multiple environments provide different viewing contexts, including a home setting, traditional theatre, home theatre and a space / void environment.

Challenges & Solutions

Streaming video content across devices: A local Wi-Fi based communication and streaming workflow allows client devices to connect to MyTvR and provide selected video content for playback inside the headset.

Performance & Optimization

Creating different immersive viewing experiences: Multiple virtual spaces give users different ways to experience their content. Each environment provides a distinct visual and spatial context while maintaining the core media-viewing functionality.
