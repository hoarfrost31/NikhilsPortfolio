XR / Unity Project

Rage Rooms

A VR experience where players can pick up a baseball bat and smash everyday office objects to release some frustration.

XR/VRGame

Project Overview

Rage Rooms focuses on simple, physical interactions and satisfying impact feedback through a playful office environment.

Key Features

  • Grab and use a baseball bat to interact with the environment
  • Smash PCs, printers, mugs and other office props
  • Objects break on impact and respawn at their original locations
  • Particle effects provide visual impact feedback
  • Physics-based interactions create a natural feeling when hitting objects

Technical Implementation

Engine: Unity
Language: C#
Platform: VR
Focus: XR Interaction Toolkit, physics, object interaction, particle effects

Two-handed / variable bat handling

XR Interaction Toolkit was used to maintain expected object behavior across different grab orientations.

Impact feedback & object reset

Particle effects make impacts feel responsive, while destroyed objects are restored for repeatable sessions.

Performance & Optimization

Physics interactions, destructible props and particle feedback were balanced to preserve a responsive VR experience.
