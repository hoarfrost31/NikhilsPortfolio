Unity Project

Church Scene

A cinematic walkthrough of a detailed church environment, created to explore Unity’s real-time rendering and lighting capabilities.

Walkthrough

Project Overview

The camera moves through the scene to showcase the environment, lighting and visual atmosphere.

Key Features

  • Detailed 3D church environment
  • Baked lighting for realistic illumination
  • Reflection probes for more accurate reflections
  • Cinemachine-driven camera movement
  • Cinematic walkthrough presentation

Technical Implementation

Engine: Unity
Focus: Lighting, baked GI, reflection probes, Cinemachine, environment rendering

The scene was built as part of my Lighting with Unity Udemy course, using the project to demonstrate practical lighting and rendering workflows. Baked lighting and reflection probes improve the visual quality of the environment, while Cinemachine handles camera movement through the scene.

Teaching Context

This project was developed as part of my Unity lighting curriculum and became one of the practical projects used to teach real-time lighting and rendering.

Udemy course rating: 4.2 / 5 average rating

Performance & Optimization

Baked lighting and reflection probes were used to balance visual quality with real-time environment rendering.
