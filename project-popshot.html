XR / Unity Project

PopShot

An experimental XR/VR game created to explore and deepen practical understanding of VR interaction systems.

XR/VRSimulation

Project Overview

PopShot is an experimental XR/VR game built as a hands-on environment for exploring how objects, controllers, UI and gameplay systems come together in an immersive experience.

The project focuses on interaction-driven design in Unity and practical VR development.

Key Features

  • XR/VR gameplay built around interactive objects and environments
  • Experimentation with VR interaction patterns and player interactions
  • Object manipulation and interaction feedback
  • Interactive UI designed for a VR environment
  • Gameplay systems driven by real-time player interaction
  • Unity-based XR development using C#

Technical Implementation

Engine: Unity
Language: C#
Platform: XR / VR
Focus: XR interaction, interactive 3D, gameplay systems

Challenges & Solutions

Designing intuitive VR interactions: I explored interaction patterns and evaluated how objects, controls and feedback behave through VR controllers.

Connecting interaction with gameplay: I connected the interaction layer with game logic and feedback so interactions could trigger meaningful gameplay behaviour.

Performance & Optimization

Performance was considered throughout development to maintain a responsive VR experience and understand the impact of real-time 3D environments. The project also provided practice with profiling and identifying potential Unity XR bottlenecks.
