XR / Unity Project

RecoVR

A VR experience designed to help people gradually become more comfortable with fear of heights through controlled exposure to virtual environments.

XR/VRTraining

Project Overview

RecoVR creates a convincing sense of height while giving the user a safe, controlled environment to experience and manage the situation.

Key Features

  • VR environments designed around height-based scenarios
  • Controlled exposure to different levels of height and intensity
  • Interactive environments designed to create a strong sense of presence
  • High-density 3D environments for greater visual realism

Technical Implementation

Engine: Unity
Language: C#
Platform: VR
Focus: XR interaction, high-density geometry, immersive environments

A key technical challenge was working with high-density geometry while maintaining a responsive VR experience. This required attention to scene complexity and performance while preserving the visual detail needed to make the environments convincing.

Challenges & Solutions

Managing a large environment without keeping the entire scene active: RecoVR represented a relatively large virtual city environment, but keeping every building and environment object active at the same time would unnecessarily increase memory usage and scene complexity. Unity Addressables were used to dynamically load and unload groups of environment objects based on the player's current location, helping control runtime memory and rendering overhead.

Balancing city-scale detail with rendering cost

The environment needed to appear detailed nearby while representing a much larger city in the distance. Low-poly exterior geometry was used for distant buildings, while buildings closer to the player's position used more detailed models. This provided the required visual scale while concentrating geometric detail where it was most visible.

Reducing rendering overhead from repeated geometry

Static Batching was used for suitable static environment objects to reduce draw-call overhead. GPU Instancing was used for repeated objects where the same mesh and material could be rendered efficiently across multiple instances.

Reducing realtime lighting cost

Since the available memory budget allowed it, the scene used baked lighting for appropriate static elements. This moved much of the lighting computation from runtime to the baking stage, reducing realtime lighting work during the VR experience.
